# App Studio 現地実施票

この文書は対象端末で事実を記録するためのchecklistである。未確認項目を禁止条件へ読み替えない。警告や遮断が出た場合は、発生操作と表示を記録し、対象機能だけを止めて相談する。

## 持込み前

- [ ] 配布folderに未署名EXE、fixture EXE、開発時 `.build`、資格情報がない。
- [ ] GitHub ZIP由来の場合、開発端末側でMark of the Webを解除した。
- [ ] 使用API、書込先、通信なしを説明できる。
- [ ] 正本hashと配布folderのhash/内容一覧を記録した。
- [ ] 出力先と持ち帰り手続を確認した。
- [ ] **録画がアプリを横断すること**を関係者へ説明し、記録してよい範囲を合意した。
- [ ] **再生が実アプリを操作すること**と、許可トグルを入れるまで実行されないことを説明した。

## 録画

- [ ] ［録画］で本体が消え、3・2・1のカウントダウンが出た。`Esc` で中止できた。
- [ ] 録画中の枠が前面ウィンドウに追従した。
- [ ] 「● 録画中 mm:ss ／ 停止」が出て、停止で終了できた。F9でも止まった。
- [ ] **2つ以上のアプリを跨いだ**。切替が `appSwitch` として記録された。
- [ ] クリックが意味のあるステップとして記録され、生のマウス移動は記録されていない。
- [ ] ショートカット（Ctrl+○）が `keyChord` として記録された。
- [ ] 通常の文字入力が **キー列ではなくテキスト欄の値変更** として記録された。
- [ ] password欄への入力が `secretInput` になり、**値がどの出力にも無いこと**を確認した。
- [ ] キーフレーム画像に枠・停止コントロール・本体が写っていない。
- [ ] キーフレーム画像でもpassword矩形が黒塗りされた。
- [ ] 取得できなかった事項が `report.html` の限界節に出た。

## 再生

- [ ] 許可トグルを入れるまで再生が実行されず、`blocked` として「何も送っていない」と記録された。
- [ ] 許可後、期待ウィンドウの前面化が確認され、来なかった場合は `failed` になった。
- [ ] 各ステップの試行列が記録された（例 `uia.InvokePattern:notSupported -> win32.BM_CLICK:success`）。
- [ ] 曖昧・不在のとき、座標へ落ちずに理由を出して停止した。停止理由:
- [ ] `secretInput` のステップで操作者への入力要求が出た。中止すると何も入力されなかった。
- [ ] 経路を `UIAのみ` / `Win32のみ` / `SendInputのみ` に狭めた場合の結果を記録した。
- [ ] 状態を変える操作が、方式比較のために二重に実行されていない。
- [ ] 緊急停止（Shift+F12）で止まり、実アプリ操作の許可が解除された。

## 出力と持ち帰り

- [ ] `runtime/sessions/<id>/out/` に `report.html` が出た。
- [ ] `out/ai/` に **`session.md` と `screens.pdf` のちょうど2ファイル**だけが出た。
- [ ] `report.html` を対象アプリなしで単体表示できた。絞込み欄と折畳みが動いた。
- [ ] 埋め込み画像が表示された。縮小した旨と原本の場所がその場に書かれていた。
- [ ] `screens.pdf` を実PDF表示で開き、ページ番号・Screen ID・画像・黒塗りを目視した。
- [ ] `session.md` に base64 が入っていない。座標が物理ピクセルである旨が書かれている。
- [ ] 容量予算で縮小・省略が起きた場合、その理由とID が `session.md` と `report.html` の両方にあった。
- [ ] 出力先を記録した:
- [ ] USB/DLPに遮断された場合、操作、時刻、製品表示を記録した。
- [ ] 値方針（`recordText` / `lengthOnly`）が全出力に明記されていた。
- [ ] `environment.writeTargets` と実際の書込場所・残留物を照合した。

## 通らなかった場合

| 事象 | 選択肢 |
|---|---|
| PowerShell/Add-Type不可 | 許可申請、署名済み構成への移行、Microsoft既製toolで最低限調査 |
| 特定APIだけ遮断 | その機能だけ止め、Win32/UIA/画像の別経路へ切替 |
| 対象が昇格 | 管理者実行の可否を確認。不可なら `WIN32-ACCESS` を記録 |
| `SetForegroundWindow` が効かない | 再生は前面化の失敗を `failed` として止める。手動で前面にしてから再開する |
| USBへ書けない | 許可された別出力先・持出し手続を確認。toolが勝手にfallbackしないことを確認 |
| 構造を公開しないアプリ | 画像が唯一の記述である旨が出力に明記されていることを確認し、座標依存の限界を関係者へ伝える |
| `SysListView32/TreeView32` の行dataが必要 | `NEEDS-B3` の実対象証拠を持ってWP-B3を別判断 |
| Java/SAPでUIAが薄い | Java Access Bridge / SAP GUI Scriptingの追加判断 |
